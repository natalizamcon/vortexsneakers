# VORTEX SNEAKERS

Sistema de gestión comercial y financiera para VORTEX SNEAKERS (Cochabamba, Bolivia):
inventario por par, compras y lotes, clientes, reservas, ventas, pagos, pedidos y entregas,
finanzas, reportes, agenda con recordatorios y usuarios con roles.

- **Tecnología:** React + TypeScript + Vite · Supabase · Netlify
- **Funciona en:** computadora, tablet y celular (se puede instalar como app)

👉 **Para ponerlo en marcha, lee `LEEME_PRIMERO.md`.**

| Carpeta / archivo | Para qué sirve |
|---|---|
| `supabase/01_base_de_datos.sql` | Crea toda la base de datos (se pega una vez en Supabase) |
| `supabase/02_administrador.sql` | Convierte tu usuario en administrador |
| `src/config.ts` | Aquí van la URL y la clave de Supabase |
| `netlify.toml` | Le dice a Netlify cómo publicar la app |
